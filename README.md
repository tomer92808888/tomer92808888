## Featured Research

### 01 — FSTab
**Feature–Security Table: Connecting Frontend Features to Backend Security Rules**

How much can an attacker learn about an application's potential vulnerabilities just by observing its interface?

FSTab investigates the relationship between observable frontend actions and backend static-analysis rules, using code-model-conditioned associations to prioritize potentially relevant security checks.

- **Focus:** AI security · Code models · Static analysis · Empirical evaluation
- **Paper:** [Read on arXiv](https://arxiv.org/abs/2602.04894)

### 02 — LEMSS
**LLM-Based Platform for Multi-Agent Competitive Search Simulation**

A research platform for studying competitive search through LLM-powered agents. The project explores multi-agent interactions and provides an experimental setting for evaluating agent strategies.

- **Focus:** Information retrieval · LLM agents · Multi-agent systems
- **Publication:** Accepted at SIGIR 2025
- **Project:** [LEMSS2025 on GitHub](https://github.com/LEMSS2025)
